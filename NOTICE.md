# Notices

## EmulationStation

The GCM frontend in the release zip is a build of Batocera's EmulationStation
(https://github.com/batocera-linux/batocera-emulationstation) with GCM's menu added
(`emulationstation/es-app/src/guis/GuiGcmNative.h`). EmulationStation remains under its own licence;
the release zip includes it as `LICENSE-EmulationStation.md`.

## Emulators and content

GCM does not include any emulator, firmware, key or game content. It manages updates and DLC that
you already own and have placed on your own storage.
